# Project Practical

This repo contains resources to support the Project Practical for the C7147 Programming for Life Sciences module at the University of Sussex, UK.

## Resources
### 📂 notebooks
- **Project practical notebook** -- Colab notebook containing Python exercises to learn about function design, testing code, and formatting outputs.
- **Project 1 assessment notebook** -- Colab notebook for Week 7 submission (also includes assessment criteria, and guidance on setting up a GitHub repo, readme, and making commits).
